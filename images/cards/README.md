# Renders das cartas

Uma pasta por tema, com um PNG transparente por personagem, numerado pela ordem da carta:

```text
images/cards/
  Piratas/
    1.png
    2.png
    ...
    24.png
```

A pasta `Piratas` já está preparada. As outras pastas podem ser criadas quando você preparar os próximos temas:

| Tema | Nome exato da pasta |
|---|---|
| Piratas | Piratas |
| Cosmos | Cosmos |
| Espíritos | Espiritos |
| Dragões | Dragoes |
| Neon | Neon |
| Expedição selvagem | Expedicao |

Cada pasta usa a sequência `1.png` a `24.png`, sem zeros à esquerda. O site associa os arquivos às cartas automaticamente. Respeite maiúsculas/minúsculas nos nomes das pastas, pois o GitHub Pages diferencia esses caminhos.

Veja o [guia completo](../../CARD_IMAGES.md) para nomes, transparência, GIFs e ajustes opcionais.
