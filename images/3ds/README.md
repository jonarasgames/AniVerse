# Capas quadradas do AniVerse para 3DS

Salve cada capa em PNG com o ID numérico do título no `anime-data.json`. Por exemplo, a capa de Lucky☆Star (ID 1) fica em `images/3ds/1.png`. Não coloque zeros antes do ID.

Use imagens quadradas. Uma resolução de 256 × 256 px já é suficiente para o 3DS. Depois de publicar os arquivos no GitHub Pages, aperte **X** no AniVerse para 3DS.

O app procura automaticamente o PNG desta pasta. Para usar um link direto do Catbox, preencha `thumbnail3ds` naquele título. Quando a imagem quadrada não estiver disponível, o app usa `thumbnail`.
