# Piratas — novembro de 2026

Coloque nesta pasta os dois arquivos da edição:

- `banner.png`: fundo completo com os personagens já montados à direita. Tamanho recomendado: **1920 × 720 px**. Deixe os **45% da esquerda** com menos detalhes para a logo aparecer bem.
- `logo.png`: título “Piratas”, com fundo transparente. Tamanho recomendado: **640 × 320 px**. Recorte margens transparentes excessivas.

O site coloca a logo à esquerda, centralizada na vertical, sobre o banner. Não coloque outra logo dentro do fundo, para não duplicá-la. O fundo aparece inteiro, mantendo a proporção, inclusive no celular. Informações e progresso ficam abaixo da arte.

Os nomes dos arquivos são exatos e em minúsculas. Publique os arquivos normalmente pelo Git. Sem o banner, o site continua usando o visual atual; sem a logo, mostra apenas o fundo e o título em texto abaixo.

Para dezembro, crie `images/seasons/2026-12/` com os mesmos nomes. Cada edição tem seus próprios arquivos; assim, os álbuns arquivados conservam suas artes. Não é preciso alterar o código para adicionar a arte do mês seguinte.
