# Banners das temporadas

Uma pasta por edição mensal, no formato `AAAA-MM`. A primeira temporada é `2026-11` (Piratas).

```text
images/seasons/
  2026-11/
    banner.png
    logo.png
  2026-12/
    banner.png
    logo.png
```

Veja as medidas e a montagem no [guia de novembro](2026-11/README.md). O banner e a logo são opcionais: enquanto você prepara a arte, o site conserva o visual padrão. As cartas continuam separadas em `images/cards/Piratas/1.png` até `24.png`.
